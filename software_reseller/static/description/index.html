Software Reseller and Consulting Services

This setup is tailored for IT companies specializing in reselling software licenses and providing consulting services. A typical sale includes a 1-year Oracle Database license, purchased from Oracle and resold to clients at a margin, along with additional services to set up and configure the database for optimal performance.

Pricing

Studio (Custom Price) + Lines of Code

This advanced module uses multiple apps and Odoo Studio, but also relies on custom lines of code (such as server actions and computed fields) for extra capabilities.

Its cost follows the Custom plan pricing found at odoo.com/pricing, plus a monthly maintenance fee for the custom code.
