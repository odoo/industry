Overview

About the technical module

This module automates the invoicing process for ongoing rental orders spanning multiple months. It systematically generates down-payment invoices for active rentals, utilizing smart proration logic to calculate precise quantities and amounts based on the specific billing period.

What is an Odoo Technical Module?

Developed by Odoo S.A, a Technical Module enhances database functionality beyond standard Odoo. It leverages Odoo Studio and custom Python scripts, meaning installation could impact your licensing fees.

Customization

Conditions of Use

Each Contact record includes a Consolidate Down Payment button. Clicking this button processes all active rental orders for that contact across one of two time frames:

  • From the start date to today: If no invoices have been created yet for the order.

  • From the latest billing date to today: If prior invoices already exist.

This feature can be executed in bulk across multiple contacts.

Limitations

  • Single Invoice per Period: Once an invoice is created for the current billing period using this action, it is no longer possible to create a second invoice for that same period via this action.

  • Fixed Dates: The dates on the rental orders are fixed and cannot be altered once the action is confirmed.
