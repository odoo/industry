Overview

About the technical module

This module streamlines product and variant conversions during inventory transfers or valuations. Beyond seamless item swapping, it automatically updates pricing, adjusts outputs based on quality levels, syncs online availability, and carries over all critical product data. Complete end-to-end traceability ensures every conversion is fully auditable.

What is an Odoo Technical Module?

Developed by Odoo S.A, a Technical Module enhances database functionality beyond standard Odoo. It leverages Odoo Studio and custom Python scripts, meaning installation could impact your licensing fees.

Customization

Conversion Eligibility Criteria

To maintain data integrity, the Convert button displays in the backend and Barcode app only when the following conditions are met:

  • Stock Availability: Stock is physically available (excludes Receipts and Dropship transfers).

  • Inventory Tracking: Inventory tracking is active ("Track Inventory" enabled).

  • Transfer Status: The transfer is in progress (status is not "Draft" or "Done").

How to Complete the Conversion Pop-Up

  • Product to Convert & Pick From: Displays the product and the specific quant, including location and Lot/Serial Number.

  • Quantity: Prevents converting more than the maximum available stock for that quant.

  • Keep Lot and New Lot:

    • Keep Lot/SN: New product inherits the existing Lot/Serial Number.

    • New Lot/SN: If unchecked, users can manually assign a new Lot/Serial Number.

  • Convert Into Options: System filters eligible products based on traceability rules.

  • Destination Location: Choose destination if multiple internal locations exist.

Backend Execution & Traceability

Once clicking on "Convert" button an Automated Manufacturing Order (MO) is executed in the background:

  • Location Accuracy: MO pulls from the exact "Pick From" location.

  • Detailed Logging: Conversion records posted to Chatter and a Conversions button added to Transfer record.

  • History Preservation: Traceability Report remains unbroken, showing full product history.

Using Variants for Product Grading

Conversions can be restricted to specific product variants using the Convert Attribute setting:

  • Restricted Attributes: When marked as "Convert Attribute," only target variants within that group are selectable.

  • Guardrail: Prevents data entry errors by ensuring conversions only into pre-approved alternatives.
