Overview

About the technical module

Excises Module aims at enabling the management and reporting of excise related products.

What is an Odoo Technical Module?

Developed by Odoo SA, a Technical Module enhances database functionality beyond standard Odoo. It leverages Odoo Studio and custom Python scripts, meaning installation could impact your licensing fees.

Pricing

Studio (Custom Price) + Lines of Code

This advanced module uses multiple apps and Odoo Studio, but also relies on custom lines of code (such as server actions and computed fields) for extra capabilities.

Its cost follows the Custom plan pricing found at odoo.com/pricing, plus a monthly maintenance fee for the custom code.

Note: You can view the exact maintenance fee by hovering your mouse over the "i" info icon next to  Lines of code .

All custom features designed for this industry package are detailed below.

Customization

Contact fiscal position

Fiscal deposit on contact side is captured through the associated fiscal position.

  • Fiscal deposit: The fiscal position allows to define whether or not a fiscal position is considered related to a fiscal deposit on the contact side.

  • Practice: To keep fiscal position consistent while allowing to capture whether or not a partner has a fiscal deposit for proper excise tax and reporting management, fiscal positions can be duplicated and relabeled: one capturing it is for fiscal deposit contacts and the other for regular contacts.

Sale orders

Accounting for excises in quotations.

  • Fiscal position: Customer fiscal position drives the application or removal of excise taxes in their quotations.

  • Tax group: Even though excise taxes may be different per sale order lines, they all fall into the same tax group.

  • Detailed columns: The sale order and invoice provide a dedicated excise column.

Excise categories

Bring your own excise categories.

  • Menu: Inventory app configuration menu provides access to excise categories.

  • Custom model: The excise category is a custom model leveraged for tax and reporting purpose coming with name, description, reporting unit and packaging tax (per unit).

  • Important note: The provided excise categories are example only and are not maintained. You are invited to check in your country the excise categories to capture depending on local regulations.

  • Automation: Adding an excise category will automatically create the corresponding excise taxes.

Products submitted to excise

Defining excise data at product level.

  • Dedicated section: The product form provides a specific section for excise related data including:

    • The selection of applicable excise category to this product;
    • The excise amount with respect to the product unit of measure, for transactions and reporting purposes;
    • The excise quantity with respect to the product unit of measure for reporting purpose;
    • The packaging units with respect to the product unit of measure, for transactions and reporting purposes.

  • Automation: Selecting an excise category will automatically add the corresponding excise tax to the product.

Excise taxes

Excise taxes leverage the python tax computation module.

  • Dependency: This module depends on the python tax computation module.

  • Automation: When creating an excise category, the corresponding excise tax is created.

  • Computation: The tax computation leverages information present in the product, the associated excise category and the sale / purchase order line to compute the tax amount.

  • Peppol: The Peppol information for excise taxes is set up in the advanced options of each tax with the tax category code Z.

  • Tax group: Excise taxes are part of a single tax group for clarity purpose.

Fiscal deposit warehouse

Configuring fiscal deposit warehouses.

  • Setting: The warehouse form provides a dedicated setting to capture that a warehouse is a fiscaldeposit.

  • Limitation: Given locations and warehouses follow a hierarchical pattern, all locations in a fiscal deposit warehouse are considered as fiscal deposit.

Excise licenses

Manage your excises with or without excise licenses.

  • Without: In absence of specified excise license, the setup assumes only one license is considered and dashboard operates from this perspective.

  • Menu: The excise licenses can be defined from the Inventory configuration menu.

  • Multiple licenses: Fiscal deposit warehouses can be assigned an excise license they belong to.

  • Important note: When using excise licenses, make sure all fiscal deposit warehouses are assigned the appropriate excise license to valid excise monitoring.

Excise monitoring and reporting

Excise related transfers are monitored and summarized in a dedicated dashboard for reporting purpose.

  • Granularity: Stock move lines is the granularity level at which processing takes place.

  • Details: The dashboard provides a readme sheet to further understand the performed computations.

  • Customization: By using a dashboard, powered by Odoo spreadsheet, one can rework at will the computations of reporting, including the addition of dimensions for more advanced processing.

  • Important note: The dashboard provides an efficient mean of processing the data captured in Odoo. It is not an official report which authorities often require to be recorded from their official portal.
