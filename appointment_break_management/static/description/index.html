Overview

About the technical module

This module streamlines gap and processing time configuration during multi-stage appointment scheduling. Beyond seamless split-service management, it automatically opens secondary calendar availability.

What is an Odoo Technical Module?

Developed by Odoo S.A, a Technical Module enhances database functionality beyond standard Odoo. It leverages Odoo Studio and custom Python scripts, meaning installation could impact your licensing fees.

Pricing

Studio (Custom Price) + Lines of Code

This advanced module uses multiple apps and Odoo Studio, but also relies on custom lines of code (such as server actions and computed fields) for extra capabilities.

Its cost follows the Custom plan pricing found at odoo.com/pricing, plus a monthly maintenance fee for the custom code.

Note: You can view the exact maintenance fee by hovering your mouse over the "i" info icon next to  Lines of code .

Customization

Break Management

Break management allows appointments to include processing gaps during which the resource is available for other bookings. The following settings can be configured on the appointment type:

  • Enable Break Management: Determines whether break management is enabled for the appointment type.

  • Break Start: Specifies the elapsed time from the appointment start until the break begins (e.g., 30 minutes after the appointment starts).

  • Break End: Specifies the elapsed time from the appointment start until the break ends and the service resumes.

Booking Availability: The interval between Break Start and Break End automatically becomes available on the calendar for secondary bookings.
