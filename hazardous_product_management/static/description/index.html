Overview

About the technical module

This module allows to capture manipulation transactions of hazardous products during interventions through Planning App and to process them for investigation and reporting purposes.

What is an Odoo Technical Module?

Developed by Odoo S.A., a Technical Module enhances database functionality beyond standard Odoo. It leverages Odoo Studio and custom Python scripts, meaning installation could impact your licensing fees.

Pricing

Studio (Custom Price) + Lines of Code

This advanced module uses multiple apps and Odoo Studio, but also relies on custom lines of code (such as server actions and computed fields) for extra capabilities.

Its cost follows the Custom plan pricing found at odoo.com/pricing, plus a monthly maintenance fee for the custom code.

Note: You can view the exact maintenance fee by hovering your mouse over the "i" info icon next to  Lines of code .

All custom features designed for this industry package are detailed below.

Customization

Categories

A dedicated model is setup to detail the hazardous product categories and reporting units.

  • A menu item is available from Planning and Inventory apps to edit those.

Products

Product form enables to define whether a product is hazardous or not by specifying its hazardous product category.

Recipients

Recipients are captured through a tag model for simplicity purpose.

  • A menu item is available from Planning and Inventory apps to edit those.

Transactions

Planning shifts provide a dedicated tab to capture hazardous product transactions during interventions.

Employee can capture in few clicks transactions with product, quantity, associated device and recipient if applicable.

Reporting

Users have access to two reporting means.

  • Dashboard: A dedicated dashboard is setup to process the hazardous product transactions in an aggregated format.

  • Reporting: The Planning app comes with an additional reporting view where user can drill down for more detailed analysis.
